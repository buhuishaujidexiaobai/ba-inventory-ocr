## 💡 为什么需要这个工具？

在进行学生养成规划、装备升阶与总力战排查时，使用「什亭之匣」（arona.icu）等辅助工具能极大帮助老师理清养成进度。然而：
- 游戏内道具、欧帕兹、技能书、光盘及装备设计图总数高达数百种；
- 每次活动或版本更迭后，手动逐一盘点并在网页端输入往往需要花费半小时以上，且极易输错漏填。

**BA Inventory OCR** 通过屏幕自动化与点阵式 OCR，在 **3 ~ 5 分钟内**全自动完成所有道具及设计图的扫描与数量统计，并智能映射到 SchaleDB 道具数据库 ID，生成标准导入 JSON。

## ✨ 核心特性

- 🛡️ **安全零风险**：
  - 纯前端 UI 模拟与本地离线截图识别，**不注入内存**、**不篡改客户端**、**不修改网络通信**。
  - *(注：港澳台服通信采用客户端生成会话密钥并通过 RSA-4096 公钥加密上报，网络被动解密在密码学上不可行且有封号风险；本工具采用纯视觉路线，稳妥无封号风险。)*
- ⚡ **异步队列引擎（v10 架构）**：
  - **自适应点阵标定**：自动根据角标位置（`x数量`）聚类推算行列间距与缩放比，自适应各种显示缩放与分辨率。
  - **生产者-消费者并行**：主线程负责极速点击与页面滚动，后台双线程并发运行 RapidOCR 识别，大幅缩短采集时间。
  - **条带哈希去重**：自动跳过空格子与重叠条带，避免冗余识别。
  - **智能到底判定**：自动识别列表底部与回弹，扫描完毕自动安全停机。
- 🔄 **智能名称映射与繁简兼容**：
  - 自动将港澳台服繁体中文转换为简体规范名称。
  - 内置人工校准的别名表（纠正 OCR 常见错字及港澳台服译名差异，如「乙太/以太」、「沃普赛克/沃尔夫塞格」等）。
  - 支持**道具列表**与**裝備設計圖列表**合并追加。
- 📦 **一键对接什亭之匣**：
  - 直接输出 `什亭之匣库存导入_OCR采集.json`，在什亭之匣「库存管理」点击导入即可立即同步。

## 🛠️ 环境准备与安装

### 1. 系统要求
- 操作系统：Windows 10 / 11
- 运行环境：Python 3.10+
- 游戏环境：《蔚蓝档案》PC 客户端（或以 `BlueArchive` 进程名运行的官方客户端/模拟器）

### 2. 克隆仓库与安装依赖
打开终端（PowerShell 或 CMD）：

```bash

cd ba-inventory-ocr

# 2. （推荐）创建并激活虚拟环境
python -m venv .venv
.venv\Scripts\activate

# 3. 安装依赖项
pip install -r requirements.txt
```

## 🚀 使用指南 (使用说明)

### 步骤 1：打开游戏并进入对应页面
1. 启动《蔚蓝档案》游戏客户端；
2. 进入游戏背包的 **「道具」**（或「裝備」）页面；
   > 💡 **提示**：无需特意滑到最顶部，采集器启动后会自动平滑滚回列表最上端。

### 步骤 2：启动自动采集
- **方式 A（推荐）**：直接双击运行仓库根目录下的 **`采集.bat`**。
- **方式 B（命令行）**：在终端运行：
  ```bash
  python ba_queue_collector.py collect
  ```

> ⚠️ **重要注意事项**：
> - 脚本会自动检测游戏窗口并置顶；
> - 采集期间（约 3 ~ 6 分钟），**请勿移动鼠标或敲击键盘**，以免打断点击与界面识别；
> - 列表全部采集完成后，程序会自动停止，并将中间采集数据保存在 `rows2.json`。

### 步骤 3（可选）：追加「裝備設計圖」
1. 道具采集完成后，手动在游戏内切到 **「裝備」** 标签页；
2. 再次双击运行 `采集.bat`（或命令行执行）；
3. 采集器会自动将裝備設計圖数据追加至 `rows2.json` 中。

### 步骤 4：生成什亭之匣导入文件
在项目目录下执行映射转换脚本：

```bash
python ba_map_items.py
```

- 该脚本会自动比对 `cache/items.min.json` 与 `cache/equipment.min.json`（若本地不存在会自动从 CDN 下载）；
- 执行完成后，将在 `输出/` 目录下生成：**`什亭之匣库存导入_OCR采集.json`**；
- 命令行会打印识别成功的道具数量、装备数量以及待复核清单。

### 步骤 5：一键导入什亭之匣
1. 浏览器访问 [什亭之匣 (arona.icu)](https://arona.icu)；
2. 登录账号并进入 **「库存管理」** 页面；
3. 点击页面右上角的 **「导入」** 按钮；
4. 选择刚刚生成的 `输出\什亭之匣库存导入_OCR采集.json` 并确认；
5. 核对并手动补齐顶部栏目的 **信用点** 与 **青辉石** 数量，保存即可！

## 📌 注意事项与已知边界

1. **货币类数据**：
   - 游戏内的信用点（金币）与青辉石位于游戏界面顶栏，不包含在道具格子里，需在什亭之匣上手动填入。
2. **学生神名文字与各类自选箱**：
   - 港澳台服的学生译名与国服/简中数据库存在一定差异，为了避免串行误映射，这类物品会被自动记录在 `ambiguous.json`（或 `待复核_选择券与神名文字.json`）中供人工核对。通常只需手动开启自选箱或录入即可。
3. **窗口误触与弹窗机制**：
   - 如果在极特殊情况下误触游戏内筛选/设置弹窗，脚本内置了弹窗关键词检测，会自动按 `ESC` 关闭弹窗并重试。
